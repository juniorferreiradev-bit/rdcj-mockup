# Governança de Repositories

- Alterações de contrato exigem revisão arquitetural.
- Adapters não devem alterar semântica de domínio.
- Providers futuros devem preservar os contratos existentes.
- Nenhum repository novo deve acessar DOM.
- Nenhuma integração ServiceNow deve ser criada nesta sprint.
- Migrações devem possuir testes de compatibilidade e rollback.
