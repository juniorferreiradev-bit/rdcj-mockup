# Governance Layer — RDCJ 2.0

A camada de governança define rastreabilidade, aprovação, auditoria e versionamento para mudanças futuras.

Pastas:

- `policies/`: políticas normativas.
- `workflows/`: fluxos de mudança.
- `approvals/`: registros/modelos de aprovação.
- `releases/`: controles de release.
- `audits/`: evidências e auditorias.

Esta camada é documental e não implementa CI/CD, GitHub Actions ou runtime ServiceNow.
