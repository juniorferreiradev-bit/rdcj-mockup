# Contrato do Agente de Documentação — RDCJ 2.0

## Pode ler

- Documentos oficiais indexados.
- Memória persistente.
- Knowledge Index.
- Context Snapshot.
- Documentation Snapshot.
- Traceability Matrix.

## Pode atualizar sem aprovação

- Índices derivados.
- Snapshots derivados.
- Relatórios de saúde.
- Documentos em `memory/documentation-generated/`.

## Exige aprovação

- Alteração de README, changelog, manual, backlog ou decisões.
- Mudança de regra de negócio.
- Mudança de arquitetura alvo.
- Alteração de mapeamento ServiceNow.
- Marcação de documento como oficial, obsoleto ou substituído.

## Saída obrigatória

Toda execução deve informar fontes, hashes, divergências encontradas, conteúdo gerado, recomendações e necessidade de aprovação.
