# ServiceNow Runtime Layer — RDCJ 2.0

Camada de preparação para futura migração e execução em ServiceNow. Esta árvore é documental e contratual.

- `tables/`: mapeamentos de tabelas existentes e propostas.
- `apis/`: operações e contratos futuros.
- `workspace/`: blueprint de experiência.
- `security/`: estratégia de acesso e segregação.
- `migration/`: planos de migração.
- `governance/`: controles operacionais e readiness.

Nenhum artefato desta pasta cria tabela, ACL, Script Include, Flow, API ou conexão real.
