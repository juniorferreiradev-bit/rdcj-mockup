# Documentation Governance v2

- Fontes oficiais: documentos normativos e memória aprovada.
- Fontes derivadas: índices, snapshots, summaries e relatórios gerados.
- Atualização: alteração da fonte → indexação → health check → snapshot.
- Aprovação: conteúdo normativo exige dono do domínio; arquitetura exige Chief Architect.
- Versionamento: Git, changelog e release associado.
