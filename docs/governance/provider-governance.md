# Provider Governance

Alterações de contrato exigem revisão arquitetural. Novos providers devem possuir testes de compatibilidade, health check, mapeamento de dados, política de fallback e plano de rollback.

Integrações externas exigem aprovação de Segurança, Arquitetura e donos do domínio. Nenhum provider deve publicar dados jurídicos sem identidade, autorização e auditoria.
