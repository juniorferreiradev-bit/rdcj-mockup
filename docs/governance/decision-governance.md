# Decision Governance

- **Decide:** dono do domínio ou Product Owner, conforme o assunto.
- **Aprova:** responsável formal pela área impactada; arquitetura aprova mudanças estruturais.
- **Registra:** Documentation Architect/Memory Agent em artefato versionado.
- **Audita:** Auditor/Compliance, com evidência e trilha de aprovação.

Decisões jurídicas, regras de classificação, workflow e segurança exigem aprovação especializada.
