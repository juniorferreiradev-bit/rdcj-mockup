# UX Agent — Matriz como produto

A Matriz RDCJ ocupa a maior área e é a primeira informação. A interface deve permitir encontrar qualquer processo rapidamente.

- Cada processo é bolha com tamanho por valor e cor N1–N4, nunca dependente apenas da cor.
- Tooltip e 360° explicam posição, quadrante, risco, recuperação, evento e revisão.
- Filtros obrigatórios: agência, superintendência, escritório, advogado, tema, status, valor, classe, ativos e risco crítico.
- Garantir pan/zoom, seleção múltipla, teclado, tooltip acessível e responsividade.
- KPIs ficam secundários; score não deve protagonizar rótulos ou hierarquia.
